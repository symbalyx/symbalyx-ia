# Symbalyx IA V14 — Todo intelligente

Base UI V13.9 conservée. Ajouts V14 :

- Todo-list intégrée dans le panneau Contexte.
- Tâches séparées Arsène / Kentin.
- Cases à cocher persistées en localStorage.
- Bouton “Générer les prochaines tâches” débloqué uniquement quand toutes les tâches sont terminées.
- Génération intelligente de nouvelles tâches selon le secteur, la recherche en cours et le cycle de travail.
- Suivi du nombre de tâches et des points réalisés par Arsène / Kentin.
- Repère de partage variable pour aider à équilibrer l'argent selon le travail réel.

Important : le repère argent est indicatif. Il ne déclenche aucun paiement automatique.
